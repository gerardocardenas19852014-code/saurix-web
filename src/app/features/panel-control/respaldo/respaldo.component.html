Respaldo y restauración

⬇️ Descargar respaldo

Todo lo que capturas en Saurix se guarda solo en el navegador de este dispositivo — nada se sincroniza solo entre computadoras todavía. Descarga un archivo con TODA la información (usuarios, proyectos, tickets, presupuesto, catálogos…) para guardarlo o llevarlo a otro dispositivo.

⬆️ Restaurar desde un respaldo

Elige el archivo .json que descargaste antes (de este dispositivo o de otro) para recuperar toda esa información aquí.

⚠️ Restaurar REEMPLAZA todo lo que ya está guardado en este dispositivo por lo que traiga el archivo — no se puede deshacer. Si no estás seguro, descarga primero un respaldo de lo que tienes ahora.
